# 05. DFS (깊이 우선 탐색, Depth-First Search)

## 개념

시작 정점에서 **갈 수 있는 곳까지 끝까지 파고든 뒤**, 더 갈 곳이 없으면 바로 전 갈림길로 돌아와 다른 길을 탐색합니다.
미로에서 "한쪽 벽만 짚고 끝까지 가 보는" 방식입니다.

```
    1
   / \
  2   3        DFS 방문 순서: 1 → 2 → 4 → 5 → 3 → 6
 / \   \
4   5   6
```

구현은 **재귀** 또는 **스택**으로 합니다.

## 그래프 표현

```python
# 간선 목록 [(1,2), (1,3), (2,4)] → 인접 리스트
graph = [[] for _ in range(n + 1)]
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)   # 무방향 그래프면 양쪽 모두 추가
```

2차원 격자(지도)는 그 자체가 그래프입니다. 상하좌우 이동을 `dx, dy` 배열로 표현합니다.

## 시간복잡도

- 인접 리스트: O(V + E) (V = 정점 수, E = 간선 수)
- 격자 N×M: O(N × M)

## 언제 쓰나?

- **연결 요소 개수** 세기 (네트워크, 섬의 개수, 유기농 배추)
- 모든 경로 탐색, 경로 존재 여부
- 백트래킹 (04 참고), 트리 순회
- 사이클 탐지, 위상 정렬

> ⚠️ **최단 거리는 DFS가 아니라 BFS**로 구하세요. DFS는 처음 찾은 경로가 최단이라는 보장이 없습니다.

## 자주 하는 실수

- **방문 처리를 빼먹어서 무한 루프**
- Python 재귀 깊이 제한(기본 1000) → `sys.setrecursionlimit(10**6)`. 그래도 격자가 크면(예: 1000×1000) 스택으로 바꾸는 편이 안전합니다.
- 격자에서 범위 검사(`0 <= nx < n`)를 빼먹거나 x/y(행/열)를 헷갈리는 경우
