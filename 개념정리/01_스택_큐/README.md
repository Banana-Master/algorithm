# 01. 스택 / 큐

## 개념

| | 스택 (Stack) | 큐 (Queue) |
|---|---|---|
| 규칙 | LIFO: 마지막에 넣은 것을 먼저 꺼냄 | FIFO: 먼저 넣은 것을 먼저 꺼냄 |
| 비유 | 접시 쌓기 | 줄 서기 |
| Python | `list` (`append`, `pop`) | `collections.deque` (`append`, `popleft`) |
| JavaScript | `Array` (`push`, `pop`) | `Array` + head 인덱스 (`shift()`는 O(N)이라 느림) |

삽입과 삭제는 모두 O(1)입니다.

## 언제 쓰나?

- **스택**
  - 괄호 짝 맞추기, 올바른 괄호 판별
  - "직전 원소"와 비교하며 제거하는 문제 (짝지어 제거하기, 같은 숫자는 싫어)
  - 단조 스택: "오른쪽에서 처음으로 나보다 큰 수" (오큰수, 주식가격)
  - 재귀를 반복문으로 바꿀 때 (DFS)
- **큐**
  - 들어온 순서대로 처리 (프로세스, 다리를 지나는 트럭)
  - BFS

## 핵심 패턴

**1) 괄호 검사**: 여는 괄호는 push, 닫는 괄호가 나오면 pop해서 짝이 맞는지 확인합니다.

**2) 단조 스택 (Monotonic Stack)**: 스택에 "아직 답을 찾지 못한 인덱스"를 쌓아 둡니다.
새 값이 스택 top보다 크면 top의 답이 확정되므로 pop합니다. 각 원소는 최대 한 번씩 push/pop되므로 O(N)입니다.

## 자주 하는 실수

- 빈 스택에서 `pop()`해서 에러가 나는 경우 → 꺼내기 전에 비었는지 확인
- 괄호 검사가 끝난 뒤 스택이 비어 있는지 확인하지 않음 (`"(("` 같은 입력)
- Python에서 `list.pop(0)`, JS에서 `shift()`로 큐를 구현해 O(N²)이 되는 경우
