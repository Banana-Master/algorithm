# 10. 누적합 / 투 포인터 / 슬라이딩 윈도우

## 누적합 (Prefix Sum)

`S[i] = A[0] + A[1] + … + A[i-1]` 을 미리 구해 두면, **구간 합을 O(1)** 에 구할 수 있습니다.

```
A = [5, 4, 3, 2, 1]
S = [0, 5, 9, 12, 14, 15]   ← 맨 앞에 0을 하나 두면 경계 처리가 편함

A[1] ~ A[3] 의 합 = S[4] - S[1] = 14 - 5 = 9  (4 + 3 + 2)
```

- 질문이 Q번 들어오는 구간 합: O(N × Q) → **O(N + Q)**
- **2차원 누적합**: `S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + A[i][j]`
  - 구간 (x1,y1)~(x2,y2) 합 = `S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]`
- **나머지 응용** (백준 10986 나머지 합): `(S[j] - S[i]) % M == 0` ⇔ `S[j] % M == S[i] % M`
  → 나머지가 같은 누적합 쌍의 개수를 세면 됩니다.

## 투 포인터 (Two Pointers)

배열 위에 포인터 두 개를 두고, 조건에 따라 한쪽씩 움직이며 O(N)에 탐색합니다.

**유형 1: 같은 방향 (연속 구간)**: `start`, `end`를 둘 다 왼쪽에서 출발
- 구간 합 < 목표 → `end`를 늘림 (원소 추가)
- 구간 합 ≥ 목표 → `start`를 늘림 (원소 제거)
- ⚠️ **원소가 모두 양수**일 때만 성립합니다 (구간을 늘리면 합이 반드시 커져야 하므로).

**유형 2: 양 끝에서 안쪽으로**: 정렬된 배열에서 두 수의 합 찾기
- 합 < 목표 → 왼쪽 포인터 +1, 합 > 목표 → 오른쪽 포인터 -1

## 슬라이딩 윈도우 (Sliding Window)

**길이가 고정된** 구간을 한 칸씩 밀면서, 새로 들어온 값은 더하고 빠진 값은 뺍니다. O(N)

## 언제 쓰나?

| 상황 | 방법 |
|---|---|
| 구간 합 질문이 여러 번 | 누적합 |
| "연속된 부분 수열의 합이 M인 경우의 수" (양수) | 투 포인터 |
| 정렬된 배열에서 합이 X인 두 수 | 양 끝 투 포인터 |
| 길이 K인 구간들의 최대 합 | 슬라이딩 윈도우 |
| 음수가 섞인 연속 부분합 = K 개수 | 누적합 + 해시 |

## 자주 하는 실수

- 누적합 인덱스를 1칸씩 헷갈림 → `S` 앞에 0을 두고 `S[r+1] - S[l]` 형태로 통일
- 음수가 있는 배열에 같은 방향 투 포인터 사용
- 누적합 값이 커서 JS에서 2⁵³을 넘는 경우 (BigInt 필요할 수 있음)
