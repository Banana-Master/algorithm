# 04. 완전탐색 / 백트래킹

## 개념

**완전탐색 (Brute Force)**: 가능한 모든 경우를 다 만들어 보고 조건에 맞는 것을 찾습니다.
가장 단순하지만 **입력이 작으면 가장 확실한 방법**입니다.

**백트래킹 (Backtracking)**: 완전탐색을 재귀로 진행하다가 **"이 길은 답이 될 수 없다"** 는 것이 확실해지면
더 들어가지 않고 되돌아옵니다(가지치기). 그래서 실제로 탐색하는 경우의 수가 크게 줄어듭니다.

```
선택 → 재귀로 다음 단계 → 선택 취소(원상복구)
```

## 경우의 수 크기

| 종류 | 개수 | 예 (N=10) |
|---|---|---|
| 순열 (N개 중 순서 있게 전부) | N! | 3,628,800 |
| 조합 (N개 중 R개, 순서 없음) | C(N, R) | C(10,5)=252 |
| 부분집합 | 2ᴺ | 1,024 |
| 중복 순열 (N개 중 R번, 중복 허용) | Nᴿ | 5⁵=3,125 (모음 사전) |

## 언제 쓰나?

- N이 작을 때 (보통 N ≤ 10이면 순열, N ≤ 20이면 부분집합)
- "모든 조합/순열 중에서", "가능한 모든 경우"
- N-Queen, 스도쿠처럼 조건을 만족하는 배치 찾기 → 백트래킹

## 구현 방법 2가지

1. **라이브러리** (Python): `itertools.permutations`, `combinations`, `product`
2. **재귀 직접 구현**: 가지치기가 필요하거나 JS를 쓸 때 (JS에는 내장 함수가 없음)

## 자주 하는 실수

- 재귀 후 **원상복구**(방문 해제, `pop()`)를 빼먹는 경우
- 결과에 `path`를 그대로 넣어서 나중에 값이 바뀌는 경우 → 복사본(`path[:]`, `[...path]`) 저장
- 중복 원소가 있는데 중복 결과를 제거하지 않음 → `set` 사용
- 소수 찾기 문제의 `"011"`처럼 앞자리 0 → `int()`로 변환하면 자연히 11이 됨
