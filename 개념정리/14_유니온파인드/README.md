# 14. 유니온 파인드 (Union-Find, 서로소 집합)

## 개념

여러 원소를 **그룹(집합)** 으로 묶고, 두 원소가 **같은 그룹인지** 빠르게 확인하는 자료구조입니다.
각 원소는 부모를 가리키고, 같은 루트(대표)를 가지면 같은 그룹입니다.

- `find(x)`: x가 속한 그룹의 대표(루트)를 찾는다
- `union(a, b)`: a의 그룹과 b의 그룹을 합친다

```
처음:  1  2  3  4  5      (각자 자기 자신이 대표)
union(1,2), union(3,4):
       1     3     5
       |     |
       2     4
union(2,4):
       1
      / \
     2   3
         |
         4            → find(4) == find(2) == 1 이므로 같은 그룹
```

## 최적화 (꼭 넣기)

- **경로 압축**: `find` 하면서 지나간 모든 원소가 루트를 바로 가리키게 만듭니다.
  `parent[x] = find(parent[x])`
- **랭크/크기 기준 합치기**: 작은 트리를 큰 트리 밑에 붙입니다.

두 가지를 적용하면 연산 하나가 사실상 O(1)입니다.

## 언제 쓰나?

- 같은 그룹 여부 판단, 그룹 개수 세기 (네트워크, 친구 관계)
- **사이클 판별**: 간선 (a, b)를 추가할 때 이미 `find(a) == find(b)`이면 사이클
- **최소 스패닝 트리 (크루스칼)**: 간선을 비용순으로 정렬하고, 사이클이 생기지 않는 간선만 선택

## 자주 하는 실수

- `parent[a] = b`처럼 **루트가 아닌 원소끼리** 연결 → 반드시 `parent[find(a)] = find(b)`
- 같은 그룹인지 비교할 때 `parent[a] == parent[b]`로 비교 → 반드시 `find(a) == find(b)`
- Python 재귀 `find`에서 깊이 초과 → 경로 압축을 넣거나 반복문으로 구현
