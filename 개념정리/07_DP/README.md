# 07. DP (동적 계획법, Dynamic Programming)

## 개념

큰 문제를 작은 문제로 나누고, **작은 문제의 답을 저장해 두었다가 다시 계산하지 않고 재사용**하는 기법입니다.

피보나치를 그냥 재귀로 구하면 `fib(3)`, `fib(2)`… 같은 계산을 수없이 반복합니다(O(2ᴺ)).
한 번 구한 값을 배열에 저장해 두면 각 값을 한 번씩만 계산하므로 O(N)이 됩니다.

```
fib(5)
├── fib(4)
│   ├── fib(3)  ← 계산
│   └── fib(2)
└── fib(3)      ← 또 계산 (DP라면 저장된 값을 바로 꺼냄)
```

## DP를 쓸 수 있는 조건

1. **겹치는 부분 문제**: 같은 작은 문제가 여러 번 등장한다
2. **최적 부분 구조**: 작은 문제의 최적해로 큰 문제의 최적해를 만들 수 있다

## 구현 방법 2가지

| | Top-down (메모이제이션) | Bottom-up (테이블) |
|---|---|---|
| 방식 | 재귀 + 저장 | 반복문으로 작은 것부터 채움 |
| 장점 | 점화식을 그대로 옮기기 쉬움 | 재귀 깊이 제한 없음, 보통 더 빠름 |
| Python 팁 | `@functools.cache` | 코테에서는 이쪽을 권장 |

## DP 문제 푸는 4단계

1. **상태 정의**: `dp[i]`가 무엇을 의미하는지 한 문장으로 쓴다. (예: "i를 1로 만드는 최소 연산 횟수")
2. **점화식**: `dp[i]`를 더 작은 상태로 표현한다. (예: `dp[i] = min(dp[i-1], dp[i//2], dp[i//3]) + 1`)
3. **초기값**: 가장 작은 상태의 값을 정한다. (예: `dp[1] = 0`)
4. **계산 순서**: 필요한 값이 먼저 계산되도록 반복문 방향을 정한다.

## 대표 유형

| 유형 | 상태 / 점화식 예시 |
|---|---|
| 1차원 | 계단 오르기: `dp[i] = dp[i-1] + dp[i-2]` |
| 2차원 격자 경로 | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` (등굣길) |
| 삼각형 / 누적 최댓값 | `dp[i][j] = max(위 두 칸) + 값` (정수 삼각형) |
| 0/1 배낭 | `dp[w] = max(dp[w], dp[w - 무게] + 가치)` (w를 **큰 쪽에서 작은 쪽으로**) |
| LIS (가장 긴 증가 부분 수열) | `dp[i] = max(dp[j] + 1)` (j < i, a[j] < a[i]) |
| LCS (최장 공통 부분 수열) | 같으면 `dp[i-1][j-1] + 1`, 다르면 `max(dp[i-1][j], dp[i][j-1])` |

## 자주 하는 실수

- `dp[i]`의 의미를 정하지 않고 바로 코드를 쓰는 경우 → 꼬이기 쉽습니다
- 초기값/인덱스 범위 실수 (0번부터인지 1번부터인지)
- 0/1 배낭을 1차원 배열로 풀 때 작은 무게부터 갱신하면 같은 물건을 여러 번 쓰게 됨
- "1,000,000,007로 나눈 나머지" 조건을 중간 계산마다 적용하지 않음 (JS는 특히 오버플로/정밀도 문제)
