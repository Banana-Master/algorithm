# 02. 해시 (Hash)

## 개념

키(key)를 해시 함수로 변환해서 값을 저장하는 자료구조입니다.
**키로 값을 찾고, 넣고, 지우는 연산이 평균 O(1)** 입니다.

| | Python | JavaScript |
|---|---|---|
| 키 → 값 | `dict`, `defaultdict`, `Counter` | `Map` (또는 객체 `{}`) |
| 중복 없는 집합 | `set` | `Set` |

## 언제 쓰나?

- "이 값이 **있는지**" 빠르게 확인해야 할 때 → `set`
- 원소별 **개수 세기** → `Counter` / `Map`
- 두 리스트의 차이 찾기 (완주하지 못한 선수)
- "두 수의 합이 target인 쌍 찾기": 지금까지 본 값을 해시에 저장
- 그룹 묶기 (같은 종류끼리 모으기: 의상, 베스트앨범)

## 핵심 패턴

**리스트에서 `x in list`는 O(N)** 이지만, **`x in set`은 O(1)** 입니다.
반복문 안에서 포함 여부를 검사한다면 먼저 set으로 바꾸세요. O(N²) → O(N)이 됩니다.

## 자주 하는 실수

- JS 객체 `{}`의 키는 문자열로 바뀝니다. `obj[1]`과 `obj['1']`은 같은 키입니다. 숫자 키가 중요하면 `Map`을 쓰세요.
- Python `dict`에 없는 키를 `d[key] += 1` → `KeyError`. `d.get(key, 0) + 1` 또는 `defaultdict(int)` 사용
- 리스트는 해시 키가 될 수 없습니다(Python). 튜플로 바꾸세요. JS에서는 배열을 키로 쓰면 참조로 비교되므로 `` `${x},${y}` `` 같은 문자열 키를 씁니다.
