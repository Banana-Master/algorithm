# 08. 그리디 (탐욕법, Greedy)

## 개념

**매 순간 지금 가장 좋아 보이는 선택**을 하고, 그 선택을 되돌리지 않는 방법입니다.
구현은 쉽지만, **"매번 최선을 고르면 전체도 최선이다"** 가 성립할 때만 정답입니다.

## 그리디가 통하는지 확인하기

- **반례를 먼저 찾아보세요.** 작은 예시 몇 개를 손으로 돌려서 그리디 답과 실제 최적해가 같은지 확인합니다.
- 예) 동전 거스름돈
  - 동전이 [500, 100, 50, 10]처럼 **큰 동전이 작은 동전의 배수**이면 큰 것부터 쓰는 그리디가 최적
  - 동전이 [1, 3, 4]이고 6원을 만들 때: 그리디는 4+1+1 = 3개, 최적은 3+3 = 2개 → **그리디 실패, DP로 풀어야 함**

## 대표 패턴

| 문제 | 그리디 기준 |
|---|---|
| 회의실 배정 (최대한 많은 회의) | **끝나는 시간이 빠른 순**으로 정렬 후 겹치지 않으면 선택 |
| ATM (대기 시간 합 최소) | 처리 시간이 **짧은 사람부터** |
| 구명보트 | 정렬 후 **가장 가벼운 + 가장 무거운** 짝 시도 (투 포인터) |
| 큰 수 만들기 | 스택: 앞자리가 클수록 좋으므로, 더 큰 수가 오면 앞의 작은 수를 제거 |
| 단속카메라 | 나가는 지점 순 정렬, 카메라를 구간 끝에 설치 |

대부분 **정렬 + 한 번 훑기**로 O(N log N)입니다.

## 자주 하는 실수

- 증명 없이 직감으로 그리디를 적용 → 반례에 걸림. 애매하면 DP나 완전탐색을 먼저 고려
- 정렬 기준을 잘못 고름 (회의실 배정에서 시작 시간으로 정렬하면 틀림)
- 동점일 때의 정렬 기준을 빼먹음 (회의실 배정: 끝나는 시간이 같으면 시작 시간순)
