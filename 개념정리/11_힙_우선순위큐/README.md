# 11. 힙 / 우선순위 큐 (Heap / Priority Queue)

## 개념

**가장 작은(또는 큰) 값을 빠르게 꺼낼 수 있는** 자료구조입니다.
완전 이진 트리 형태로, 부모가 항상 자식보다 작습니다(최소 힙).

```
        1          ← 루트가 항상 최솟값
      /   \
     3     2
    / \   /
   7   4 5
```

| 연산 | 시간복잡도 |
|---|---|
| 삽입 (push) | O(log N) |
| 최솟값 꺼내기 (pop) | O(log N) |
| 최솟값 보기 (peek) | O(1) |

매번 정렬하면 O(N log N)이지만, 힙은 넣고 빼는 것을 반복해도 각각 O(log N)입니다.

## 언어별 사용법

**Python**: `heapq` (최소 힙만 제공)
```python
import heapq
h = []
heapq.heappush(h, 3)
heapq.heappop(h)          # 최솟값 꺼내기
heapq.heappush(h, -x)     # 최대 힙은 부호를 뒤집어서 넣고, 꺼낼 때 다시 -
heapq.heappush(h, (우선순위, 값))  # 튜플은 첫 원소 기준으로 비교
```

**JavaScript**: 내장 힙이 없으므로 **직접 구현**해야 합니다. (example.js의 `MinHeap` 클래스를 복사해서 쓰세요)

## 언제 쓰나?

- "가장 작은/큰 것을 꺼내고, 새 값을 넣고"를 **반복**하는 문제 (더 맵게, 카드 정렬하기)
- 다익스트라 최단 경로 (13 참고)
- 상위 K개 유지하기 (크기 K인 최소 힙)
- 작업 스케줄링 (디스크 컨트롤러)

## 자주 하는 실수

- Python `heapq`는 최소 힙뿐입니다 → 최대 힙은 `-값`
- 리스트를 만든 뒤 `heapify` 없이 바로 `heappop` → 힙 구조가 아니라서 틀린 값이 나옴
- 한 번만 최솟값이 필요하면 힙 대신 `min()`으로 충분합니다
