# 13. 최단 경로: 다익스트라 (Dijkstra)

## 개념

**간선마다 비용(가중치)이 다른** 그래프에서, 한 시작점으로부터 모든 정점까지의 최단 거리를 구합니다.
(비용이 모두 같으면 06 BFS로 충분합니다.)

**아이디어**: "아직 확정되지 않은 정점 중 **지금까지 거리가 가장 짧은 정점**은 더 짧아질 수 없다"
→ 그 정점을 확정하고, 그 정점을 거쳐 가는 길로 이웃의 거리를 갱신합니다.
가장 짧은 정점을 매번 빠르게 찾기 위해 **최소 힙**을 사용합니다.

```
1. dist[시작] = 0, 나머지는 무한대
2. 힙에서 (거리, 정점) 중 거리가 가장 작은 것을 꺼낸다
3. 이미 더 짧은 거리로 처리된 정점이면 건너뛴다
4. 이웃 next에 대해 dist[v] + 비용 < dist[next] 이면 갱신하고 힙에 넣는다
5. 힙이 빌 때까지 반복
```

## 시간복잡도

O(E log V) (E = 간선 수, V = 정점 수)

## 최단 경로 알고리즘 고르기

| 상황 | 알고리즘 | 복잡도 |
|---|---|---|
| 간선 비용이 모두 같음 | BFS | O(V + E) |
| 비용이 0 또는 1 | 0-1 BFS (덱 사용) | O(V + E) |
| 비용이 양수, 시작점 하나 | **다익스트라** | O(E log V) |
| 음수 간선 존재 | 벨만-포드 | O(V × E) |
| 모든 정점 쌍 사이 거리, V ≤ 500 정도 | 플로이드-워셜 | O(V³) |

## 자주 하는 실수

- **음수 간선이 있으면 다익스트라는 틀립니다**
- 힙에서 꺼낸 거리가 `dist[v]`보다 크면(이미 더 짧은 경로로 처리됨) 건너뛰는 처리를 빼먹어 시간 초과
- 방향 그래프인데 양방향으로 간선을 넣거나, 그 반대
- 무한대 값을 너무 작게 잡음 → Python `float('inf')`, JS `Infinity`
