# 12. 정수론 (소수, 최대공약수, 최소공배수)

## 1) 소수 판별: √N 까지만 나눠 보기

N이 a × b로 나누어떨어진다면 a와 b 중 하나는 반드시 √N 이하입니다.
따라서 **2부터 √N까지만** 나눠 보면 됩니다. → O(√N)

```
36 = 1×36 = 2×18 = 3×12 = 4×9 = 6×6   ← √36 = 6 을 기준으로 대칭
```

## 2) 에라토스테네스의 체: 범위 안의 소수를 한꺼번에

N 이하의 소수를 **모두** 구할 때 씁니다. → O(N log log N)

1. 2부터 N까지 모두 "소수 후보"로 둔다
2. 아직 지워지지 않은 가장 작은 수 i는 소수다 → i의 배수를 모두 지운다
3. i × i > N 이 될 때까지 반복 (i의 배수 지우기는 **i × i부터** 시작해도 된다)

> 소수 판별을 여러 번 해야 한다면, 체로 한 번에 구해 두는 것이 훨씬 빠릅니다.

## 3) 최대공약수 (GCD): 유클리드 호제법

`gcd(a, b) = gcd(b, a % b)`, `gcd(a, 0) = a` → O(log min(a, b))

```
gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6
```

## 4) 최소공배수 (LCM)

`lcm(a, b) = a × b / gcd(a, b)` (오버플로를 막으려면 `a / gcd(a, b) × b` 순서로)

여러 수의 LCM은 앞에서부터 차례로: `lcm(lcm(a, b), c) …`

## 5) 약수 구하기

1부터 √N까지 i가 약수이면 `N / i`도 약수입니다. → O(√N)

## 언어별

| | Python | JavaScript |
|---|---|---|
| GCD | `math.gcd(a, b)` | 직접 구현 |
| LCM | `math.lcm(a, b)` (3.9+) | 직접 구현 |
| 큰 수 | 정수 크기 제한 없음 | 2⁵³ 넘으면 `BigInt` (`10n`) |

## 자주 하는 실수

- 0과 1을 소수로 처리 (소수는 2부터)
- 소수 판별 반복문을 N까지 돌려 시간 초과
- JS에서 `a * b`가 2⁵³을 넘어 정밀도가 깨짐
