# 03. 정렬 (Sorting)

## 개념

내장 정렬은 O(N log N)이며, 직접 구현할 일은 거의 없습니다.
중요한 것은 **"무엇을 기준으로 정렬할지"** 를 정하는 것입니다.

| | Python | JavaScript |
|---|---|---|
| 오름차순 | `arr.sort()` / `sorted(arr)` | `arr.sort((a, b) => a - b)` |
| 내림차순 | `arr.sort(reverse=True)` | `arr.sort((a, b) => b - a)` |
| 여러 기준 | `key=lambda x: (x[1], -x[0])` | `(a, b) => a[1] - b[1] \|\| b[0] - a[0]` |

## 언제 쓰나?

- K번째 수, 중앙값, 상위 N개
- 정렬한 뒤 **그리디**: 회의실 배정(끝나는 시간순), 구명보트(가벼운 + 무거운 짝)
- 정렬한 뒤 **투 포인터 / 이분 탐색**
- 문자열 비교 기준 정렬: 가장 큰 수 (`a+b`와 `b+a` 비교)

## 자주 하는 실수

- **JS의 `sort()`는 기본이 문자열 정렬입니다!** `[10, 9, 1].sort()` → `[1, 10, 9]`. 숫자는 반드시 `(a, b) => a - b`를 넘기세요.
- Python `arr.sort()`는 `None`을 반환합니다. `arr = arr.sort()`라고 쓰면 arr가 None이 됩니다.
- 원본을 유지해야 하면 Python은 `sorted()`, JS는 `[...arr].sort()` 또는 `arr.toSorted()`
- 실패율 같은 문제에서 동점일 때 기준(작은 번호 먼저 등)을 빼먹는 경우
